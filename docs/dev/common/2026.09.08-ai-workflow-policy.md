# AI 개발 워크플로우

공통 안전 경계는 저장소 루트 AGENTS.md의 Safety Guardrails를 따른다.
이 정책은 Astra뿐 아니라 같은 저장소를 쓰는 모든 모델에 적용한다.
위험도는 파일 수보다 영향, 데이터 민감도, 되돌리기 가능성으로 분류하며 여러 조건에 걸리면 높은 등급을 쓴다.

## 작업 분류

| 등급 | 대상 | 진행 기준 |
| --- | --- | --- |
| T0 | 정확한 오타·단일 표현 수정 | 직접 수정과 관련 확인. 별도 PRD나 타당성 인터뷰 없음 |
| T1 | 범위가 정해진 문서·표현·동작 보존 유지보수 | 요청을 작업 명세로 사용. 기존 task/branch 재사용, 필요 시 Beads task |
| T2 | 새 화면, API, 사용자 동작·도메인 규칙 변경 | intake로 미결정 범위를 정하고 해당 구현·품질 단계 수행 |
| T3 | 인증·권한·결제·스키마·삭제·배포·하네스 승인 경계 | T2 절차에 해당 보안/성능 검토 추가. 외부 영향·비가역 작업은 실행 전 확인 |

모호한 요청은 위험도와 범위를 먼저 확인한다. 이미 승인된 계획·브랜치·Linear 예외는 이어받는다.
Beads 추적을 사용하되 한 작업마다 epic과 자식 이슈를 만들 필요는 없다. 읽기 전용 감사는 추적용 외부 변경을 자동으로 만들지 않는다.

## 읽기와 의사결정

관련 Skill을 선택하고 필요한 참조만 읽는다. 같은 세션에서 이미 읽은 내용은 변경되지 않았다면 재사용한다.
제품·공개 계약·권한·비용·데이터·비가역성에 영향을 주는 미결정 사항은 사용자와 논의한다.
이름, 내부 구성, 기존 패턴 적용 등 가역적인 구현 선택은 기존 관례로 해결하고 의미 있는 가정만 보고한다.
새 계약을 임의로 정하거나 기존 제품 동작을 바꾸는 선택을 “내부 구현”으로 분류하지 않는다.

## 검증

- 개발 중에는 관련 검사를 먼저 실행한다. 실패가 이번 변경 때문이면 범위 안에서 수정하고 영향받는 검사를 다시 실행한다.
- 앱 동작 변경은 AGENTS.md Verification Defaults의 최종 lint·타입·도메인 테스트를 수행한다. 지금은 격리 환경과 CI 보장 범위를 실증하지 않았으므로 이를 축소하지 않는다.
- 문서·지시문만 바뀌면 앱 테스트 대신 diff, 참조, 지시 일관성을 확인한다. 하네스 변경은 harness-security 검토를 추가한다.
- 이미 통과한 검사는 소스·의존성·설정·실행 환경이 동일할 때 재사용하고 근거를 남긴다. 관련 변경이나 새 실패가 있으면 다시 실행한다.
- 전체 lint 뒤 동일한 파일 lint를 관성적으로 반복하지 않는다.
- 필요한 E2E의 준비가 안 되었으면 미실행 이유를 보고하고 검증 완료로 표시하지 않는다.
- “로컬”이라는 이름만으로 격리를 가정하지 않는다. 비밀값을 읽지 않고 설정·fixture 등으로 데이터와 외부 접속 범위를 확인한다.

T1의 작은 변경은 동일 세션 검토를 허용한다. T2/T3 품질 검토는 지원되는 도구의 독립 컨텍스트 평가를 사용한다.
독립 검토를 실행하지 못했다면 그 한계를 표시하고, 수행하지 않은 리뷰를 통과했다고 보고하지 않는다.

## 완료와 권한

목표, 대상, 완료 검사, 자율 범위, 정지 경계가 요청에 있으면 그대로 사용한다. 빠진 정보 중 실제 결과를 바꾸는 것만 질문한다.
요청 범위의 로컬 구현·검증·실패 수정까지 이어간다. 원인과 무관한 실패는 별도로 보고한다.
검증 성공은 커밋·push·PR·merge·배포 허가가 아니다. 승인된 커밋은 같은 범위에서 재확인하지 않지만, 원격 작업은 Safety Guardrails의 실행 직전 승인을 따른다.
현재 release Skill은 없으므로 자동 호출하거나 존재한다고 가정하지 않는다. 명시적 release 요청은 관련 운영 문서와 현재 도구를 확인한 뒤 처리한다.

## 평가

변경의 효과는 아직 실측하지 않았다. 이후 작업에서 위험도, 중간 질문, 반복 검사, 리뷰 반려, 회귀를 Beads 작업 기록에 남겨 비교한다.
질문이나 테스트 실행이 줄어도 오류·범위 이탈이 늘면 해당 완화를 되돌린다. CI 자동화와 모델별 실험은 별도 후속 범위다.
